## 🌟 Overview
This is the personal portfolio website of **Vivek Vishwakarma**, Senior DevOps & Multi-Cloud Infrastructure Engineer. Designed with a cybernetic dark-mode aesthetic, glassmorphism, interactive command-line terminal (`vsh`), dynamic DevSecOps pipeline visualizer, and production enterprise projects.

## 🛠️ Tech Stack & Architecture
- **Multi-Cloud:** Microsoft Azure (AKS, VNet Hub-Spoke, Key Vault RBAC, Private Endpoints) & AWS (EKS, VPC, IAM)
- **Infrastructure as Code (IaC):** Terraform (HCL 90%), OpenTofu, Checkov
- **Automation & Scripting:** YAML (90%), Linux Bash (70%), PowerShell (65%), Python (60%)
- **Enterprise DevSecOps:** Checkmarx (SAST), Black Duck (SCA), Aqua Security, Trivy, SonarQube
- **Observability & SRE:** Datadog APM, Prometheus, Grafana, Azure Monitor

## 🚀 How to Run Locally
Open `index.html` directly in any modern browser, or run a lightweight local HTTP server:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
